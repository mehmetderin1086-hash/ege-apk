# Ritim implementation contract

iOS 17+, Swift 5 language mode, SwiftUI, Combine ObservableObject @MainActor. No third-party iOS packages.

## Shared core (root implements)
`MediaKind: String, Codable, CaseIterable { case audio, video }`
`MediaTrack: Identifiable, Codable, Hashable`: id UUID, title String, artist String, kind MediaKind, fileName String, duration Double, addedAt Date, isFavorite Bool, playCount Int, lastPlayedAt Date?, sourceURL String?, fileSize Int64. `colorIndex: Int` derived stable from UUID. `subtitle: String` derived artist/kind. All required initializer fields have defaults except title and fileName. `MediaPlaylist`: id UUID, name String, trackIDs [UUID], createdAt Date.
`LibraryStore: ObservableObject`: @Published tracks [MediaTrack], playlists [MediaPlaylist], errorMessage String?; init seeds bundled ORIGINAL demonstration tracks once; `url(for: MediaTrack) -> URL`; `importFiles(_ urls:[URL]) async`; `importDownloadedFile(_ url: URL, title: String?, artist: String?, sourceURL: String?) async throws -> MediaTrack`; `toggleFavorite(_ track:MediaTrack)`; `delete(_ track:MediaTrack)`; `createPlaylist(name:String)`; `deletePlaylist(_ playlist:MediaPlaylist)`; `add(_ track:MediaTrack, to playlist:MediaPlaylist)`; `remove(_ track:MediaTrack, from playlist:MediaPlaylist)`; `tracks(in playlist:MediaPlaylist) -> [MediaTrack]`; `recordPlay(_ track:MediaTrack)`; `rename(_ track:MediaTrack,title:String,artist:String)`; `storageBytes:Int64`.

## Playback (playback agent)
`PlaybackStore: ObservableObject`: `init(library:LibraryStore)`; @Published current: MediaTrack?, queue:[MediaTrack], isPlaying:Bool, elapsed:Double, duration:Double, shuffleEnabled:Bool, repeatMode:RepeatMode (.off,.all,.one), playbackRate:Float, sleepDeadline:Date?, errorMessage:String?; `player:AVPlayer` (stable instance); `play(_ track:MediaTrack, in tracks:[MediaTrack])`; `togglePlayPause()`; `next()`; `previous()`; `seek(to:Double)`; `enqueue(_ track:MediaTrack)`; `removeFromQueue(at offsets:IndexSet)`; `moveQueue(from:IndexSet,to:Int)`; `cycleRepeatMode()`; `setRate(_ value:Float)`; `setSleepTimer(minutes:Int?)`; `stop()`.

## Downloads (root implements)
`DownloadFormat:String,CaseIterable,Identifiable { case mp3,mp4 }`
`DownloadEntry:Identifiable,Codable`: id UUID, title:String, sourceURL:String, format:DownloadFormat, progress:Double, status:DownloadStatus (.queued,.preparing,.downloading,.completed,.failed,.cancelled), error:String?, serverID:String?, trackID:UUID?. `status.title:String`. `isActive:Bool` computed.
`DownloadStore:ObservableObject`: init(library:LibraryStore); @Published entries:[DownloadEntry], serverURL:String (persisted), errorMessage:String?, serverStatus:String; `start(url:String,format:DownloadFormat)`; `cancel(_ entry:DownloadEntry)`; `retry(_ entry:DownloadEntry)`; `clearFinished()`; `checkServer() async`. Token stored in Keychain via `apiToken:String` computed get/set with objectWillChange. Direct media HTTPS URLs downloaded natively; YouTube submitted to service. Progress/status persist. UI accepts user URLs, not arbitrary embedded browser extraction. Server endpoint configurable in Settings. Local development uses .local host and NSAllowsLocalNetworking, production HTTPS.

## Views (UI agent)
`RootView` reads @EnvironmentObject library:LibraryStore, playback:PlaybackStore, downloads:DownloadStore. Full SwiftUI UI in Views only. Native artwork with colors/shapes, no web asset dependency. UI handles real empty state, search, library sorting/filter, playlists create/add/remove, favorites, downloads with MP3/MP4 selection and errors/progress/cancel/retry, settings server URL/token/test, full player with video, queue, sleep timer, speed, AirPlay via AVRoutePickerView, import Files. Stable accessibilityIdentifiers for tests: tab.home/tab.search/tab.library/tab.downloads; import.files; player.expand; player.playPause; download.url; download.start. Use confirmationDialog for deleting files. Dynamic Type accessible buttons. Main app supplies objects.

## Service API (backend agent)
Python localhost/LAN API on 8765. GET /health (public) returns {status:"ok", ...}. Protected API Bearer token. POST /v1/jobs body {url,format:"mp3"|"mp4"} => job. GET /v1/jobs/{id} => job. DELETE /v1/jobs/{id} => cancels. Job shape {id,status:"queued"|"preparing"|"downloading"|"completed"|"failed"|"cancelled",progress:0..1,title,artist,error?,download_path?}. GET /v1/jobs/{id}/file => media file when complete. YouTube public links only, no DRM bypass/private content cookies. yt-dlp subprocess fixed args (no shell), ffmpeg MP3/MP4 conversion, finite queue and size/duration/runtime limits, persistent jobs, cancellation, startup recovery, auth and URL validation. Config token via env/file generated by startup, never hardcode into app/repo. Local script can show connection URL but must not print tokens in tool output. Tests for auth, URL validation, cancellation and mocked process integration.
